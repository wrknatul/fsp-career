# Mock FSP registry data

`registry.json` is generated by `python -m app.fsp_registry.generate` (run from `backend/`) and
read by `MockFspRegistry`. Do not edit it by hand: change `generate.py` and regenerate.
`python -m app.fsp_registry.generate --check` fails when the file is out of date.

Every record is fictional: names, birth dates, regions, competition titles and protocol links
(`https://fsp.example/protocols/...`). The demo candidate is `FSP-2024-00117`.
