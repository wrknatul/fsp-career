ФСП.Карьера

Платформа подбора ИТ-специалистов с обратной механикой: соискатель не откликается, а собирает подтверждаемый профиль. Работодатель находит его по категории «стек × грейд × роль × формат» и сам присылает оффер с зарплатой.

Видео без звука, 2 минуты 25 секунд: запись прототипа с подписями к каждому шагу. Не воспроизводится — откройте файл напрямую.

Что на видео

  1. Соискатель входит: профиль пустой, категории нет.
  2. Привязывает ФСП ID — результаты подтверждает реестр.
  3. Загружает резюме — навыки и опыт разобраны правилами.
  4. Сдаёт экспресс-тест — навык подтверждён.
  5. Видит грейд и из чего он сложился.
  6. Работодатель открывает матрицу «стек × грейд».
  7. Ищет обычным текстом, видит объяснение оценки.
  8. Отправляет оффер с суммой — контактов ещё не видит.
  9. Соискатель принимает — стороны получают контакты.

Запустить у себя

git clone https://github.com/wrknatul/fsp-career
cd fsp-career
docker compose up --build

Через пару минут откройте http://localhost:8088 и нажмите «Войти в демо как соискатель» или «Войти в демо как работодатель».

  • Соискатель: demo.candidate@fsp-career.test
  • Работодатель: demo.employer@fsp-career.test
  • Пароль демо-учёток: demo12345

Нужны только Docker и Docker Compose. Данные реестра ФСП в прототипе смоделированы.
